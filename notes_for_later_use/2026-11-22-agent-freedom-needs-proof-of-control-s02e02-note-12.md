# More freedom for the agent, more proof of control

Date: 2026-11-22
Topic: I do not need to limit the agent with strong, fixed capabilities; the smarter the models, the more freedom I can give, and the more control I need to prove everything is still mine
Lecture: S02E02 Building an Agent, part "Core features" (figure 3, the filters interface)

I want to come back to this as a design rule: declare a scope (interface, rules, limits), let the agent act freely inside it, and put the proof in mechanisms (walls, permissions, a journal), not in prompts.

Where it is written: [Lecture 2: 12, section 7](../Week2_Lecture_2_Building_an_Agent/12_Sandbox_For_Agent_Code_Pi_And_Search_Execute.md#7-freedom-lives-inside-a-scope-and-the-wall-proves-it). Open: what proof I would accept for each kind of freedom, and the article's question of projects that used a filter the agent later modified.

Second level: the agent manages not only filters but tools, panels and workflows; the CRUD principle stays, the flexibility grows. Interface, rules and limits stay fixed by me. The figure is in the same section of note 12.
